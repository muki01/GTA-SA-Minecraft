# Security Policy

GTA SA Minecraft is an ASI plugin that runs inside GTA San Andreas on your own computer. It does not connect to the internet.

## Supported versions

Only the [latest release](https://github.com/muki01/GTA-SA-Minecraft/releases/latest) receives fixes.

## Reporting a vulnerability

If you find a security problem, for example a crafted save or settings file that makes the game run code, please **don't open a public issue**. Report it privately instead: on the repository's **Security** tab, click **Report a vulnerability**.

You will get an answer as soon as possible. Once a fix is released, the report can be made public.

Only download the mod from this repository's [Releases page](https://github.com/muki01/GTA-SA-Minecraft/releases). Copies uploaded elsewhere may be modified.
